# Outreach Pilot — README

This repository contains the ready-to-use materials for a 30-day outreach pilot you can sell and fulfill manually.

Files in repo
- landing_page.md — one-page landing copy to paste into Notion/Carrd
- invoice_email.txt — ready-to-send invoice email text
- pilot_agreement.md — short one-page agreement to use with clients

What I just added
- This README (deployment + playbook, 1-week schedule, sample messages, tracking sheet columns)

How to personalize (quick)
1. Replace placeholders in landing_page.md, invoice_email.txt, and pilot_agreement.md:
   - [Your name / Business] or [Your name]
   - [Insert calendar link]
   - [PASTE PAYPAL/STRIPE INVOICE LINK HERE]
   - [Company Name]
2. Commit changes or edit directly in GitHub (open the file in the repo and click the pencil icon).

Publish the landing page (Notion / Carrd)
- Notion (free): create a new page, paste landing_page.md content, add an image from Unsplash, set the page to public, copy the public link and add it to your outreach messages.
- Carrd (free): choose a simple template, paste copy into text blocks, upload hero image, set CTA buttons to your calendar and invoice links.

Create invoices (zero cost options)
- PayPal: Business or personal account can create and send invoices from the web dashboard. Copy the invoice link into invoice_email.txt.
- Stripe: Use Stripe Invoicing (no monthly fee). Create an invoice and share the hosted invoice link.
- Bank transfer / Zelle / Cash App: add instructions in the invoice email if you prefer.

Tracking & fulfillment (manual SOP)
- Create a Google Sheet with these columns:
  - id, prospect_name, title, company, website, linkedin, email, source, outreach_channel, message_version, date_sent, follow_up_1_date, follow_up_2_date, reply, meeting_date, meeting_notes, status, notes
- Use a new row per prospect and update status as you go.
- Send messages in small daily batches to avoid deliverability issues (20 LinkedIn invites/day or 10–20 emails/day).

1-week outreach schedule (repeatable cadence)
Day 1: Send initial batch (10–20 emails or 20 LinkedIn invites)
Day 2: Send outreach QA + follow up to any early replies
Day 3: Send second batch
Day 4: First follow-up to Day 1 prospects
Day 5: Send third batch
Day 6: Second follow-up to Day 1 prospects and first follow-up to Day 3 prospects
Day 7: Review metrics, book demos, prep weekly report to client

Sample messaging (edit per prospect)
LinkedIn connection (short)
Hi [Name], I help web design agencies book higher-value clients through personalized outreach. Can I send one quick sample message for a prospect to show what this looks like?

Cold email — first outreach
Subject: Quick pilot to book clients for [Company]

Hi [Name],

I saw your recent work on [example client or project]. I help web design agencies land higher-value clients by sending personalized outreach that actually converts. I’ll run a 30‑day pilot: 50 tailored messages + reply handling for $299. If you get meetings, great — if not, I’ll refund $100.

Interested in a 15‑minute call to get started?

Best,
[Your name]

Follow-up (3–5 days after first)
Hi [Name],

Just following up — I can send a free sample message for one prospect if you want to see how it reads. Quick 2‑line example and I’ll leave it at that.

Thanks,
[Your name]

Reply handling scripts (short)
- Positive reply: Great — can we lock a 15-minute slot? Here’s my calendar: [CALENDAR LINK]
- Objection — too busy: Totally understand — if you send 5 target companies I’ll do 1 free sample outreach and show results.
- Price objection: We can start smaller (25 messages) or offer a booking guarantee option.

End-of-pilot report (one page)
- Total messages sent: X
- Replies: Y
- Meetings booked: Z (list date/time and prospect)
- Top 3 message variants that worked
- Next recommended step (e.g., continue outreach, scale to automation, managed service)
